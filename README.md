Информационная система для автоматизации работы медицинской организации (поликлиники, стационара, частного медицинского центра).

---

## 📋 О проекте

**Центральная сущность системы** — электронная карта пациента, вокруг которой строятся все бизнес-процессы.

Система автоматизирует:
- Ввод карточки пациента
- Запись на приём
- Ведение медицинских записей (диагнозы, назначения)
- Формирование выписки
- Оформление больничного листа
- Формирование отчётности

---


## 🎯 Цели проекта

| Цель | Описание |
| :--- | :--- |
| **Централизация данных** | Создание единого хранилища электронных карт пациентов |
| **Снижение ручного труда** | Автоматизация рутинных операций регистратуры и врачей |
| **Повышение прозрачности** | Обеспечение руководства актуальной аналитикой |
| **Обеспечение преемственности** | Формирование целостной истории взаимодействия с пациентом |
| **Сокращение времени обслуживания** | Уменьшение времени записи и получения результатов |

---

## 🔄 Ключевые бизнес-процессы

| Процесс | Описание |
| :--- | :--- |
| **Ввод карточки пациента** | Регистрация нового пациента, заполнение персональных данных, создание электронной карты |
| **Запись на приём** | Выбор врача, даты, времени, фиксация визита |
| **Ведение медицинских записей** | Внесение диагнозов, назначений, рекомендаций |
| **Выписка** | Формирование выписного эпикриза, закрытие случая лечения |
| **Больничный** | Оформление листка нетрудоспособности |
| **Формирование отчётности** | Генерация внутренних и внешних отчётов |
