# 1. Анализ предметной области

## 1.1. Общая характеристика

Предметная область — автоматизация работы медицинской организации (поликлиники, стационара или частного медицинского центра). Основной объект управления — электронная карта пациента, вокруг которой строятся все бизнес-процессы.

## 1.2. Основные сущности

**Пациент** — физическое лицо, получающее медицинские услуги.

**Электронная карта пациента** — совокупность данных о пациенте, анамнезе, диагнозах, назначениях, результатах обследований.

**Медицинский персонал** — врачи, медсёстры, администраторы.

**Приём** — взаимодействие врача и пациента в определённое время.

**Выписка** — завершение лечения, формирование итогового документа.

**Отчётность** — статистические и аналитические формы для управления учреждением.

## 1.3. Бизнес-процессы

Из документа выделены ключевые процессы:

- **Ввод карточки пациента** — регистрация нового пациента, заполнение персональных данных, создание электронной карты.
- **Запись на приём** — выбор врача, даты, времени, фиксация визита.
- **Выписка** — формирование выписного эпикриза, закрытие случая лечения.
- **Формирование отчётности** — генерация внутренних и внешних отчётов (например, для Минздрава, страховых компаний).

## 1.4. Проблемы существующей организации (вероятные)

- Разрозненность данных (бумажные карты, отдельные Excel-файлы).
- Ошибки при записи пациентов (двойная запись, наложения).
- Трудности с формированием отчётности вручную.
- Низкая прозрачность загрузки врачей.
- Отсутствие единой истории взаимодействия с пациентом.
