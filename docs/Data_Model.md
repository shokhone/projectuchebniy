# Выбор технологического стека
## Система управления медицинской лабораторией

---

## 1. Общие положения

В данном документе представлено обоснование выбора технологического стека для разработки **Системы управления медицинской лабораторией**. Выбор основан на анализе требований к системе, характере решаемых задач и особенностях учебного проекта.

---

## 2. Критерии выбора технологий

| № | Критерий | Описание |
|---|----------|----------|
| 1 | **Простота освоения** | Низкий порог входа, хорошая документация |
| 2 | **Быстрота разработки** | Наличие готовых решений и фреймворков |
| 3 | **Надёжность** | Стабильность работы и проверенность временем |
| 4 | **Поддержка хостингов** | Широкая доступность на большинстве хостингов |
| 5 | **Сообщество** | Активное сообщество, множество готовых библиотек |

---

## 3. Основной язык программирования

### PHP

В качестве основного языка программирования используется **PHP**. Данный язык специально предназначен для веб-разработки, позволяет быстро создавать динамические веб-приложения и имеет низкий порог входа для начинающих разработчиков.

**Преимущества выбора:**

| № | Преимущество | Описание |
|---|--------------|----------|
| 1 | **Простота изучения** | Интуитивно понятный синтаксис, множество обучающих материалов |
| 2 | **Веб-ориентированность** | Создан специально для веб-разработки |
| 3 | **Большое сообщество** | Огромное количество готовых решений и библиотек |
| 4 | **Доступность хостингов** | Поддерживается практически всеми хостинг-провайдерами |
| 5 | **Актуальность** | Современные версии PHP (8.x) обеспечивают высокую производительность |

**Версия:** PHP 8.1 или выше

## 4. Среда разработки

### Visual Studio Code

В качестве среды проектирования и разработки используется **Visual Studio Code**. Данная среда имеет интуитивно понятный интерфейс, поддерживает работу с современными веб-технологиями, расширениями и системой контроля версий Git.

**Преимущества выбора:**

| № | Преимущество | Описание |
|---|--------------|----------|
| 1 | **Бесплатность** | Полностью бесплатная среда разработки |
| 2 | **Лёгкость** | Быстрый запуск, низкое потребление ресурсов |
| 3 | **Расширения** | Огромный магазин расширений для PHP, MySQL, Git |
| 4 | **Встроенный терминал** | Удобная работа с командами Git и Composer |
| 5 | **Интеграция с Git** | Встроенные инструменты контроля версий |

**Рекомендуемые расширения:**

| Расширение | Назначение |
|------------|------------|
| PHP Intelephense | Интеллектуальная поддержка PHP |
| PHP Debug | Отладка PHP-кода |
| MySQL | Работа с базой данных |
| Thunder Client | Тестирование API |
| GitLens | Расширенная работа с Git |

## 5. Веб-фреймворк

### Laravel

В качестве основного веб-фреймворка выбран **Laravel**. Laravel является самым популярным PHP-фреймворком, предоставляет широкий набор инструментов для быстрой разработки веб-приложений, включая ORM, маршрутизацию, аутентификацию и работу с базой данных.

**Преимущества выбора:**

| № | Преимущество | Описание |
|---|--------------|----------|
| 1 | **Быстрая разработка** | Множество встроенных инструментов "из коробки" |
| 2 | **Eloquent ORM** | Удобная работа с базой данных через модели |
| 3 | **Blade шаблонизатор** | Простой и мощный язык шаблонов |
| 4 | **Встроенная аутентификация** | Готовые решения для авторизации и регистрации |
| 5 | **Миграции** | Управление структурой базы данных через код |
| 6 | **Большое сообщество** | Множество пакетов, документация, форумы |

**Альтернативы, которые рассматривались:**

| Технология | Плюсы | Минусы | Решение |
|------------|-------|--------|---------|
| Symfony | Мощный, профессиональный | Сложный порог входа | ❌ Отклонён |
| CodeIgniter | Лёгкий, быстрый | Меньше функциональности | ❌ Отклонён |
| Yii2 | Высокая производительность | Меньше сообщества | ❌ Отклонён |

**Итоговый выбор:** ✅ **Laravel 10.x / 11.x**

## 6. Система управления базами данных

### MySQL

В качестве системы управления базами данных выбрана **MySQL**. MySQL является наиболее популярной реляционной СУБД для веб-приложений на PHP, обеспечивает высокую производительность, надёжность и отлично интегрируется с Laravel.

**Преимущества выбора:**

| № | Преимущество | Описание |
|---|--------------|----------|
| 1 | **Популярность** | Самая распространённая СУБД для PHP-приложений |
| 2 | **Совместимость** | Отличная интеграция с Laravel и PHP |
| 3 | **Производительность** | Высокая скорость выполнения запросов |
| 4 | **Бесплатность** | Open Source лицензия |
| 5 | **Поддержка хостингов** | Доступна на всех хостингах |

**Альтернативы, которые рассматривались:**

| Технология | Плюсы | Минусы | Решение |
|------------|-------|--------|---------|
| PostgreSQL | Больше функциональности | Меньше распространён на хостингах | ✅ Запасной вариант |
| SQLite | Не требует сервера, простота | Не подходит для многопользовательской работы | ✅ Для разработки |

**Итоговый выбор:** ✅ **MySQL 8.x** (продакшен) / **SQLite** (разработка)

## 7. Серверное окружение

### OpenServer / XAMPP / Docker

Для локальной разработки используется **OpenServer** или **XAMPP** — готовые сборки, включающие веб-сервер Apache/Nginx, PHP и MySQL.

**Преимущества:**

| № | Преимущество | Описание |
|---|--------------|----------|
| 1 | **Быстрая установка** | Готовое окружение "под ключ" |
| 2 | **Простота настройки** | Минимальные требования к конфигурации |
| 3 | **Кроссплатформенность** | Работает на Windows, Linux, macOS |

**В производственной среде:**

| Компонент | Рекомендация |
|-----------|--------------|
| Веб-сервер | Nginx / Apache |
| PHP | 8.1+ с модулями: pdo, mysqli, mbstring, json, openssl |
| База данных | MySQL 8.x |
