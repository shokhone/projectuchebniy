# Техническое задание
## Система управления медицинской лабораторией

---

## 1. Общие сведения

### 1.1 Название системы
Система управления медицинской лабораторией

### 1.2 Назначение системы
Система предназначена для автоматизации работы медицинской лаборатории, включая регистрацию пациентов, назначение анализов, внесение результатов, формирование протоколов и печать бланков.

### 1.3 Основание для разработки
Разработка выполняется в рамках учебного проектирования по дисциплине «Проектирование информационных систем».

---

## 2. Цели разработки

- автоматизация процессов лаборатории;
- сокращение времени обработки данных;
- снижение количества ошибок при вводе и обработке результатов;
- удобное хранение и поиск информации о пациентах и анализах;
- обеспечение прозрачности всех этапов лабораторных исследований.

---

## 3. Пользователи системы

| № | Роль | Описание |
|---|------|----------|
| 1 | Администратор | Управление пользователями, настройка системы, резервное копирование |
| 2 | Регистратор | Регистрация пациентов, создание заказов на анализы, выдача результатов |
| 3 | Лаборант | Внесение результатов исследований, формирование протоколов |
| 4 | Врач / оператор | Просмотр протоколов, анализ результатов |

---

## 4. Функциональные требования

Система должна обеспечивать:

| ID | Требование | Описание |
|----|------------|----------|
| 4.1 | Регистрация пациентов | Внесение персональных данных пациента в систему |
| 4.2 | Хранение данных пациентов | Сохранение всех данных в структурированном виде |
| 4.3 | Поиск пациентов | Поиск по ФИО, дате рождения, номеру карты |
| 4.4 | Назначение анализов | Выбор одного или нескольких анализов из справочника |
| 4.5 | Ведение справочника анализов | Добавление, редактирование и удаление видов анализов |
| 4.6 | Внесение результатов исследований | Ввод результатов (ручной или автоматический) |
| 4.7 | Просмотр и редактирование результатов | Изменение внесённых результатов с сохранением истории |
| 4.8 | Формирование протоколов | Автоматическое создание протокола по результатам |
| 4.9 | Печать бланков и протоколов | Вывод на печать готовых документов |
| 4.10 | Хранение истории анализов | Сохранение всех анализов пациента для отслеживания динамики |

---

## 5. Нефункциональные требования

| № | Требование | Описание |
|---|------------|----------|
| 5.1 | Удобный пользовательский интерфейс | Интуитивно понятный, с чёткой навигацией |
| 5.2 | Высокая скорость работы | Время отклика основных операций не более 2 секунд |
| 5.3 | Надёжное хранение данных | Регулярное резервное копирование, защита от потери |
| 5.4 | Разграничение прав доступа | Разные роли имеют разные уровни доступа |
| 5.5 | Возможность расширения системы | Модульная архитектура для добавления нового функционала |
| 5.6 | Обеспечение целостности данных | Валидация ввода, контроль ссылочной целостности |

---

## 6. Структура системы

Система состоит из следующих модулей:

| № | Модуль | Назначение |
|---|--------|------------|
| 6.1 | Модуль регистрации пациентов | Ввод, редактирование и поиск данных пациентов |
| 6.2 | Модуль назначения анализов | Создание заказов, выбор анализов из справочника |
| 6.3 | Модуль результатов | Ввод, просмотр и редактирование результатов |
| 6.4 | Модуль формирования протоколов | Генерация PDF-протоколов на основе результатов |
| 6.5 | Модуль печати документов | Печать бланков направлений и протоколов |
| 6.6 | Модуль справочников и отчётности | Управление справочниками, формирование отчётов |

---

## 7. Входные данные

| № | Тип данных | Описание |
|---|------------|----------|
| 7.1 | Данные пациента | ФИО, дата рождения, контакты (телефон, email) |
| 7.2 | Список анализов | Перечень назначенных исследований |
| 7.3 | Результаты исследований | Числовые и текстовые значения, референсные интервалы |

## 8. Выходные данные

| № | Тип данных | Формат | Описание |
|---|------------|--------|----------|

| 8.3 | Отчёты по анализам | HTML / Excel | Статистика по выполненным исследованиям |
